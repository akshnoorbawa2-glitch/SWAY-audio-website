# SWAY Website

Official cinematic landing page for **SWAY** — Intelligent audio control for Windows.

## 🚀 Overview

- **Minimal, Obsidian & Violet Aesthetic**: Glassmorphism, subtle glowing violet accents, and dark obsidian layers.
- **Cinematic Audio Stream**: Interactive cascading audio-control cards (Spotify, Discord, YouTube, System Sounds, Focus Mode, EQ).
- **Interactive Sound-Ducking Simulation**: Real-time WASAPI audio ducking simulation widget.
- **Pure Web Technologies**: Built with clean HTML5, CSS3, and JavaScript with 60 FPS GPU-accelerated animations.

## 📦 Project Structure

```
├── index.html     # Semantic landing page structure
├── index.css      # Custom stylesheet with glassmorphism & responsive layouts
├── app.js         # Parallax tilt, scroll dynamics & sound mixer simulation
├── hero-bg.png    # Background waveform visual artwork
└── README.md
```
