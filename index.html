How SWAY operates

Zero audio redirection, zero virtual audio drivers, and no microphone permissions.

01

Audio Meter Polling

SWAY uses the Windows Audio Session API (WASAPI) to query endpoint volume meters at low-overhead 50ms intervals.

02

Rule Evaluation

When an active audio session matches your trigger list (like Chrome or Edge), SWAY calculates the duck target factor.

03

Smooth Fading & Restore

Target applications smoothly step down to your configured percentage and return to original volume once trigger audio stops.

Features and Architecture

Designed as a native desktop utility with minimal resource consumption.

Targeted Process Control

Select individual media players to duck (Spotify, Apple Music, VLC, Tidal, MusicBee) without affecting communications, wallpaper audio, or video games.

Custom Fade Curves

Configure fade-down duration, fade-up duration, restore delay, and duck percentage directly from the dashboard or settings file.

Quick Search Launcher

Access settings, toggle ducking states, inspect session logs, and exit the utility via a keyboard-driven launcher with Alt + Space.

Zero Background Servers

The audio engine compiles directly as a headless Windows GUI subsystem executable (/target:winexe) without browser extensions or command prompt windows.
