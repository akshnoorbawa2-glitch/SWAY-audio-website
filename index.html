CAPABILITIES

Surgical Audio Control

Designed as a high-performance Windows utility without audio virtualization drivers.

01 Process Isolation

Targeted Media Routing

Isolate designated media players (spotify.exe, AppleMusic.exe, vlc.exe). Discord voice chats, games, and system alerts stay at 100% volume.

02 Spotlight Interface

Alt + Space Quick HUD

Press Alt + Space anywhere to search controls, toggle ducking rules, check active session meters, or exit the background engine instantly.

03 Linear Envelope

Smooth Gain Interpolation

Transitions are calculated across configurable millisecond durations (1000ms attack, 1500ms restore delay, 1000ms release) to eliminate sudden clicks.

04 WASAPI Engine

Native Core Audio COM

Communicates directly with Windows Audio Sessions. Zero virtual audio drivers, zero audio lag, no microphone permissions, and no external servers.
